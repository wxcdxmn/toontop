# TOONTOP · Venera 漫画源

[tontop.io](https://toontop.io) 的 Venera 漫画源。接口优先、网页兜底的双通道实现。

## 特性

| 能力 | 说明 |
| --- | --- |
| 首页浏览 | 最近更新 / 热门 / 今日趋势 / 新上架 / 上升最快 / 高分更新 / 精选，共 7 个区块 |
| 题材分类 | 72 项真实题材（从站点 `/genres` 接口全量拉取，非硬编码猜测），支持状态与排序筛选 |
| 搜索 | 关键词搜索，支持中英文，分页完整 |
| 详情 | 封面、简介、作者、状态、题材标签、统计信息 |
| 章节 | 全量章节目录（站点详情页只给 50 条预览，这里走完整接口取 74 条） |
| 阅读 | 章节页取全量正文图（接口 `/images` 只返回前 3 张预览，这里取完整 13 张） |

## 双通道设计

站点同时提供公开 API（`api.toontop.io`）和服务端渲染页面。源内部按以下顺序取数：

1. 先请求接口，成功则直接用，速度最快
2. 接口失败（限流、改版、网络异常）自动回落到网页 SSR 解析，走 `__NEXT_DATA__` 内联 JSON
3. 两套数据源字段名不同，源内已做归一化映射，对外表现一致

这一点在站点接口不稳定时能显著提升可用性。

## 图片防盗链

图片域名 `rx.toontop.io` 有 Referer 校验，不带 `Referer: https://toontop.io/` 会直接返回 **403**。
源内已通过 `onImageLoad` / `onThumbnailLoad` 自动下发该请求头，无需手动配置。

## 安装

### 方式一：源列表索引（App 支持时）

在 Venera「漫画源」→「漫画源列表」填入：

```
https://cdn.jsdelivr.net/gh/wxcdxmn/toontop@main/index.json
```

国内直连可用。`raw.githubusercontent.com` 请勿使用，部分网络下会超时。

### 方式二：直接导入源文件

下载 `toontop.js`，在「漫画源」→ 添加源 → 从文件导入。
